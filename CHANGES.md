# Changes

This file records the main changes made to the Chhabra Legal Advisers website.

## Current Version

### Website branding and contact options

- Updated the page title and visible branding to **Chhabra Legal Advisers**.
- Added the office phone number and email address in the top contact bar.
- Added quick-access buttons for WhatsApp, phone calls, and enquiries.
- Added an appointment call-to-action that links to the enquiry section.

### Navigation and homepage

- Added navigation for the homepage, services, practice areas, gallery, and contact sections.
- Added a services dropdown with the firm’s main legal service areas.
- Added a branded hero banner with rotating slides and navigation dots.
- Updated the homepage sections to present the firm’s approach, services, practice areas, and contact information.

### Gallery

- Added a dedicated legal practice and chambers gallery in `index.html`.
- Added professional gallery images and descriptive captions in the `img/` folder.
- Added a lightbox viewer so visitors can open gallery images and read their descriptions.
- Added responsive gallery styling in `css/gallery.css` and gallery behavior in `js/gallery.js`.

### Styling and assets

- Added the visual styling for the branded layout, responsive sections, buttons, navigation, and enquiry form in `css/style.css`.
- Added legal-themed typography, icons, imagery, and responsive behavior.
- Retained the original template libraries under `lib/` for animations, easing, filtering, and carousel support.
